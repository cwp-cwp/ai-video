# 导演规则（本项目自建）

> 这套规则是为「AI 视频创作平台」的字段结构写的：直接对应 `shotType` / `cameraMovement` / `duration` /
> `staging.segments` / `msrVideoPrompt` 这些字段，不是通用教材。
> 核心判断只有一句：**先问这一镜要观众读到什么，再决定用多大景别、怎么动、多长**。

---

## 一、剧本层

### 1. 每场必须改变一件事
场戏结束时，信息 / 权力关系 / 情绪 / 物理状态 / 风险，至少有一项和开头不同。
没有变化的场次删掉或合并——哪怕它写得很美。

### 2. 对白在做事，不在说明
每一句台词都在**争取、回避、试探、逼迫、或者重新定义关系**。
- 检验方法：把台词单独拎出来，问"这句话想让对方做什么"；答不上来就删。
- 删掉所有互相解释"我们已经知道的事"的对白。
- 想表达"我很生气"，写"你手抖了"。

### 3. 每句自己写的台词都要能变成演员的一个动作或表情
转不成的，删掉或改写成动作。这是最有效的去 AI 味手段。

### 4. 第一拍就是钩子
全片第一个镜头要有异常、冲突或信息缺口。不要风景开场、不要空镜铺陈。
竖屏（9:16）尤其：前 3 秒决定观众划不划走。

### 5. 结尾落在画面上
钩子要是一个可见的动作、一个物件、一个表情，不是旁白总结。

### 6. 场景/角色/道具名要能对上
剧本里出现的每个名字，后面都要能建成资产、被分镜引用。**逐字一致**，别写"老李"和"李叔"两个称呼。

---

## 二、分镜层

### 1. 每镜只干一件事

给每镜写清三段：**起点 → 唯一动作 → 终点**。

```
起点：她站在窗边，右手垂着
唯一动作：抬手把窗帘拉开一道缝
终点：手指停在缝边，光打在眼睛上
```

- 涉及交接、换手、放下的，把**接触者、接触方式、物件落点**写在同一链里，不能让物件在镜外瞬移。
- 终点要能成为下一镜的可信起点。做不到，中间就缺一镜。
- 切镜必须带来变化：信息、权力、情绪、空间、节奏，至少一项。相邻两镜同景别同角度同关系 = 这次切镜没职责，并回一镜。

### 2. 景别是"读者站在多远"，不是情绪音量旋钮

| 景别 | 它唯一擅长的事 | 代价 |
|---|---|---|
| 远景 | 交代地理、人与环境的力量对比、让人被空间吞掉 | 读不到表情 |
| 全景 | 建立空间、孤立感、群体权力 | 细节弱 |
| 中景 | 互动、手势、双人策略、清楚的走位 | 情绪不够近 |
| 中近景 | 对话距离、还留着手的单人 | 最常见的工作档 |
| 近景 | 决定、证据、被藏住的反应 | 丢了空间参照 |
| 特写 | 一张脸/一只手/一处伤成为本镜唯一事实 | 观众读不到周围 |
| 大特写 | 只留眼睛、指节、物件一处细节 | 信息最少，必须有"非看不可"的理由 |

**常见错误**：情绪一升级就换更紧的景别。正确做法是问"必须被读到的信息在哪个尺度上"——
证据在指节上就给大特写，后果在两人的距离上就不该切近。

**竖屏（9:16）的现实**：宽度只有 16:9 的三分之一，横向铺开的信息会挤在一起。
所以竖屏以**中景、近景、特写**为主，远景/全景少用；要交代空间就用**纵深分层**
（前景：桌沿/门框/人的肩背；中景：主体；后景：环境），而不是往两边排。

### 3. 运镜按"这一镜在做什么"选

不要凭感觉。从上往下对，**第一行匹配的就用它**：

| 这一镜在做什么 | 运镜 |
|---|---|
| 人物在移动（冲、追、逼近、爬高） | 跟拍 / 横移，让他位置保持住 |
| 新信息从画外或画面一侧进来 | 摇 / 俯仰 / 后拉，停在新信息上 |
| 一句台词或一个认知压到某人身上 | 缓推 / 前移，停在承受者的脸或手上；关系变远则拉开 |
| 处境在原地被重新评估（绕过去才看到的另一面、被围住） | 环绕 |
| 高度本身有意义（交全局 / 把观众接进人物高度） | 升降 |
| 情绪爆发、重大反转 | 短促推近（**只留给峰值**） |
| 观察、等待、紧张、受困、插入镜、这句台词没带来压力变化 | 固定 |

- **固定是最后一行**，不是默认值。选固定也要写出理由（"这句台词没落到谁身上"）。
- 一镜只做一件事：不要同时推 + 摇 + 手持。
- 没有明确切换时，不要在同一时间段既固定又移动。

### 4. 时长 = 观众能读清几件事

**关键认知：动作塞多了不会被删掉，会被压扁。**
模型会把 6 个动作压进 5 秒里，每个半秒，看起来像快进——比少写更糟。

超载信号，命中任一条就拆：
- 一个人在几秒内要依次完成多件需要看清的事（拿起→放下→再拿另一件→起身）
- 几个角色各有独立大动作，而这镜的目的只需要一次揭示
- 长台词 + 情绪转折 + 精细手部动作 + 复杂运镜挤在一镜
- 终点没有停留时间，只能写"最后到达"

修法顺序：**删没功能的动作 → 合并能连贯的 → 选一个注意中心，其余人只留反应 → 仍放不下就拆镜或延长**。
绝不在提示词里加"快速""依次"来硬塞。

**时长参考**（按动作量调，不是配额）：

| 内容 | 秒 |
|---|---|
| 特写/大特写（单一信息） | 2–4 |
| 近景（台词一句 + 反应） | 3–6 |
| 中景/中近景（互动、走位、一段对白） | 4–8 |
| 全景/远景（建立空间、人物走位） | 5–10 |
| 复杂调度 / 长对白（一个完整段落） | 8–15 |

**单镜上限 15 秒**（H3 官方上限，平台不额外限制）。

> **不要为了"画质更稳"把所有镜头压到 8 秒以内。** 短镜头画质确实更稳，但代价是：
> 一句 12 秒的长台词拆成两镜，观众要重新进入一次情绪，人物位置、光线、表演都要重新对齐，
> 拼起来反而更碎更假——**分镜之间的接缝比单镜画质的损失更明显**。

**按语义单元切，不按秒数切**：
- 一段完整的话 / 一个完整的动作过程 = 一个镜头，哪怕 10–12 秒
- 一句话里有转折，就在转折处切
- 只有超过 15 秒才必须拆，且拆在**句号处**（语义停顿），不要在逗号处硬切

短于 2 秒的镜头除了冲击点少用。

### 5. 对白场怎么切

- **一句台词一个镜头**：说话者的镜头承载这一句；句中转折可在转折处切。
- **重要的一句落下时，切到听的人**——让观众看见它打中了谁。这是最便宜的情绪镜头。
- 交锋用正反打，保持同一轴线工作侧。
- 顺序：先一个带人物和动作的交代镜 → 落到中景/中近景 → 只在要落地的一句切特写。
- 既没台词也没动作的镜头删掉。
- **插入镜是免费的节奏工具**：手机屏、手、戒指、证件、门把手，不需要表演，可以插在长台词或等待中间。

### 6. 镜长从哪来（不要按字数折算）

1. **排时间线**：把本场每句台词 + 关键声音事件 + 必须看清的无声动作排成一条时间线，这条线的长度就是本场时长。
2. **算镜数**：本场时长 ÷ 目标平均镜长（一般 3–5 秒），四舍五入。
3. **放切点**：切在换人说话、听者反应、动作变化、插入镜处。
4. **回算**：平均镜长明显偏长 → 补听者反应和插入镜；明显偏短 → 合并没带来新信息的切点。

目标平均是**整场**的平均，不是每镜配额。插入镜可以不到 1 秒，要落地的一句可以 5 秒。

### 7. 对白估时（决定镜长的硬约束）

先排声音，再定镜长。**不要先定一个短镜长，再让人物加快语速**。

- 无录音时按原文估：中文口播约 **4 字/秒**（克制语气），含句内停顿再加 20%。
- 一句台词超出目标镜长 → **拆到说话者和听者的两个镜头上**，声音连续、画面切换、语速不变。
- 边说边抬眼的并行动作与台词共用时间；必须等说完才发生的动作另占时间。
- 开口前留 0.3–0.5 秒，说完后留 0.5–1 秒反应。

## 三、调度层（`staging.segments`）

一段戏要在同一空间里成立，先定**锚点**，再定每个人的位置。

1. **锚点**：这个空间里不动的东西（门、桌、窗、楼梯）。所有位置都相对锚点描述。
2. **轴线**：两人对话定一条线，摄影机只在**同一侧**拍（180° 规则）。A 在画右看向左，B 就在画左看向右。
3. **每人三件套**：`facing`（身体朝向）+ `gaze`（视线落点）+ `distance`（离镜头几米）。三者必须自洽——
   写"身体朝左、视线朝右"就矛盾了，除非有明确理由（回头、被叫住）。
4. **多角色**：写清**相对距离**（"甲在乙左后方一步"），不要各自独立描述。
5. **机位段**：一镜内如果换了机位（推近、绕过），就拆成多个 segment，`fromSec/toSec` 不能重叠或留空。

常见的错误是"站位只写谁在谁旁边"——那样生成出来人物会随机站。必须给**相对镜头的距离和朝向**。

## 四、提示词层

### 1. 图片提示词（资产）

固定配方顺序，逐段写：

```
主体与身份锚点 → 当前状态/变体 → 构图与视角 → 光色与材质 → 背景边界 → 禁止项
```

- **开头先写对象和用途**，不要用风格词淹没身份。第一句就该让人知道这是谁、什么年龄、什么体型。
- **身份锚点要锁死**：年龄段、脸型、发型长度与颜色、体型、标志性特征。跨镜头一致性全靠它。
- 变体只改允许变化的部分（换衣服不改脸）。
- **场景板**要有地理结构（入口在哪、主要家具位置）、视角（平视/俯视）、以及光的方向与色温。
- **道具板**要有尺度参照（"巴掌大"）、材质、磨损程度。
- 避免无验证作用的质量词堆砌（"8K、杰作、最佳质量"这类对当前模型基本无效）。
- 明确文字政策：画面里要不要出现文字、logo、水印。

### 2. 视频提示词（镜头）

固定结构，按顺序写：

```
静态视觉锚点 → 起点 → 唯一动作（触发 / 接触 / 落点）→ 次级反应 → 运镜 → 声音 → 终点
```

示例：

> 中景 35mm，女人背对镜头站在窗前，右手垂着；她抬手把窗帘拉开一道缝；手指停在缝边；镜头极缓慢推近到侧脸；雨声压过远处车流；光打在眼睛上，她眨了一下。

要点：
- **从可见起点开始，以可验证终点结束**。不要写"她回忆起了往事"这种拍不出来的东西。
- 主体、动作对象、方向、幅度、速度、先后关系都要明确。
- 表演写**动作和反应**，不写抽象结果（"她很绝望" → "她慢慢蹲下去，手撑着墙"）。
- 运镜和人物动作不要抢注意力：人在做大动作时，镜头就别再推。
- 只写本镜需要的声音，不擅自加 BGM 描述。
- 默认声明**不生成字幕和文字叠加**（模型很容易乱加字）。
- 保持短（用户偏好 60–120 字）。删掉平台能自己推断的（分辨率、画幅、模型名）。

### 3. 要删掉的词 vs 要保留的词

| 删 | 留 |
|---|---|
| 很美、震撼、电影感、高级、氛围感 | 光线方向、材质、颜色、动作、时间、距离 |

"电影感"是结论，不是画面。**把结论翻译成可拍摄的事实**，这是这份工作最核心的手艺。

## 五、镜头之间的衔接

这是"看起来像剪出来的片子"和"看起来像一堆片段"的分界线。

### 1. 续接默认开着，只在会串戏时关

平台默认 `usePrevVideoRef: true` + `prevVideoFrames: 5`（第 1 镜没有上一镜，为 false）。
这是产品默认行为，**不要批量关掉** —— 那等于主动放弃系统提供的跨镜连贯性。

| 情况 | 处理 |
|---|---|
| 换场（空间/地点完全变了） | **关**（否则上一场的画面会带进来） |
| 时间跳跃、蒙太奇段落 | **关** |
| 其余全部（含换景别、换机位、正反打、同场对话） | **默认开** |

关掉的镜头要记下来，在交付说明里点名哪几镜、为什么关。

写分镜 JSON 时**不要显式写这个字段**让默认值生效；只有确实要关的镜头才写 `false`。

### 2. 三组匹配，至少做到一组

- **动作匹配**：上一镜抬手，下一镜手已落下（中间省略过程）。
- **视线匹配**：A 看向画右，下一镜 B 在画左看回来。这是对话戏的骨架。
- **方向匹配**：他从画左出画，下一镜从画右进画。方向反了观众会以为他回去了。

### 3. 转场手法（优先用前三个，都是"看不见的剪辑"）

| 手法 | 做法 | 用在哪 |
|---|---|---|
| 声音先行 | 下一场的声音提前 0.5–1 秒进入 | 场景转换，最省力的高级感 |
| 动作切 | 在动作运动过程中切 | 加速、省略 |
| 特写过渡 | 插入物件/手部特写再切回 | 时间跳跃、情绪缓冲 |
| 遮挡转场 | 人物走过镜头挡住画面，下一镜从遮挡后开始 | 换场 |
| 空镜 | 雨、烟、灯、车流 | 呼吸、抒情、省略 |
| 跳切 | 同机位同景别硬切 | 焦躁、时间压缩（慎用） |
| 白场/黑场 | 直接切到全白/全黑 | 强段落分隔（长时间跨度） |

### 4. 节奏曲线

- 镜头长度要有起伏，不要平均。典型一场：4 → 3 → 2 → 5（最后留长镜收）。
- 高潮段缩短（1.5–3 秒）+ 增加景别变化。
- 每 8–12 个镜头安排一次"呼吸"：空镜、静止、一段环境声。
- 不要卡着台词尾就切，留 0.3–0.5 秒反应。

## 六、声音（短剧最容易被忽略的一半）

- `soundEffect` 不要空着，写**具体声源**：`雨打铁皮棚，远处电动车驶过`，不是"环境音"。
- 三层结构：**环境底噪**（持续）+ **动作音效**（点状：开门、拔刀、摔杯）+ **情绪音**（音乐/心跳）。
- 关键动作必须有动效，这是"质感"的来源。
- 静音也是设计：高潮前 0.5 秒把所有声音抽掉，冲击力翻倍。

## 七、AI 生成的现实约束

| 问题 | 规避 |
|---|---|
| 人物脸漂移 | 所有镜头沿用同一段外貌描述 + 参考图；不要中途改描述 |
| 手部畸变 | 避免手指特写、复杂握持；改用遮挡、远景、或只给手背 |
| 多角色肢体接触穿模 | 用正反打代替拥抱/推搡；必须接触时给中景不给特写 |
| 长镜头动作崩坏 | 单镜 ≤ 15 秒；动作超过 3–4 个就拆镜，不要靠压时长硬塞 |
| 运动模糊/抖动 | 少用快速摇移；`cameraMovement` 优先"缓慢推/固定" |
| 画面文字乱码 | 画面里不要出现招牌、屏幕、书页、报纸 |
| 口型对不上 | 台词镜用近景/侧脸，避免正面大特写说长句 |
| 多人同框位置乱 | 调度里写清相对距离和朝向，不要只写"两人在房间里" |

## 八、交付前自检（逐条过）

**剧本**
- [ ] 每场都有状态变化？没有的删了没？
- [ ] 每句台词都在争取/回避/试探/逼迫？有没有解释性台词？
- [ ] 第一个镜头是钩子？

**分镜**
- [ ] 每镜有唯一职责？有没有两镜在做同一件事？
- [ ] 每镜能写出"起点 → 唯一动作 → 终点"？
- [ ] 相邻两镜有没有同景别同角度（等于没切）？
- [ ] 连续多镜同景别**是允许的**（长对话、正反打、长镜头都会这样），只要机位/角度在变就是正常切镜；只有「景别+机位+运镜」全一样才需要看一眼。
- [ ] 动作量超过镜长？（数一下要看清的事，看秒数够不够）
- [ ] 每镜时长 3–15 秒，台词说得完？长对白有没有被无意义地拆碎？
- [ ] 人物/场景/道具名和资产逐字一致？

**调度**
- [ ] 每段戏有锚点？轴线上没跳？
- [ ] 每个人的 facing / gaze / distance 三件套齐了且自洽？

**提示词**
- [ ] 视频提示词是从可见起点到可验证终点？
- [ ] 光线有方向？色温有定？还是只写了"光线充足"？
